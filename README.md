# Robust and Adaptive Control

This repository collects eight university coursework assignments on robust and adaptive control. The reports document the problem setup, mathematical derivations, and results. Topics include control system analysis, controller design, and state estimation. Assignment 8 applies Kalman filtering to estimate the state of a stirred-tank reactor.

## Reports

Each assignment (1–8) includes two versions of the same report.

| --- | --- |

Download the report in your preferred language. Open `.tm` files in **GNU TeXmacs**.
